# Signal channels

The generated SignalChannelsApi handles publishing channels and notices, public discovery, offers,
codes, subscriptions, and delivery inspection. The SDK live signal history and WebSocket
subscriptions read events produced by a live run.

Keep webhook URLs and newly minted codes secret. A delayed delivery omits the notice source and
data until its due time. See the [Signal channels API guide](https://www.qtsurfer.com/docs/developers/api/signals)
for publisher and subscriber workflows.
